# DormLingua - Portal Bahasa Asrama

Aplikasi web digitalisasi pengelolaan kosakata dan kuis bahasa (Arab & Inggris) untuk lingkungan asrama/kampus.

## Fitur Utama:
1. **Autentikasi Terpisah:**
   - **Mahasiswa Santri:** Login menggunakan Nama, Semester, Asrama, dan Password.
   - **Admin / Staff (Dosen):** Login aman dengan Nama Admin dan Password fleksibel.
2. **Kuis Berpoin & Pengacakan Otomatis:**
   - Sistem pengacakan opsi jawaban (Randomize Options) agar posisi jawaban benar dinamis.
   - Sistem pengurangan poin dinamis jika salah menjawab di percobaan pertama.
3. **Leaderboard Berdasarkan Semester:**
   - Memfilter peringkat Top 20 Mahasiswa berdasarkan semester (Semester 1 s.d. 8+).
   - Dapat diakses baik oleh Mahasiswa maupun Staff/Admin.
